# wplace-kr

[wplace](https://wplace.live) 한국어 번역 (AI 번역) Tampermonkey 스크립트.

## 설치

1. [Tampermonkey](https://www.tampermonkey.net/) 또는 [Violentmonkey](https://violentmonkey.github.io/) 설치
2. [여기를 눌러](https://github.com/sungsoos/wplace-kr/raw/refs/heads/main/wplace-kr.user.js) 설치
4. [wplace](https://wplace.live)에서 언어를 한국어로 변경

## 버전 표기
`A.B.C`
`A` - 전체적인 수정
`B` - 번역 업데이트
`C` - 오류 수정
